Описание: До оптимизации видно что при изменении фильтрации или при удалении карточки задания, каждый раз происходит перерендер внутренних компонентов. А именно, FilterButton и TaskList->TaskCard. TaskCard перерендеривался при любом изменении списка до оптимизации. После оптимизации, например при удалении или смены фильтрации, карточка TaskCard уже не выполняет перерендер, так как объект task остался тем же (ссылка не изменилась), а removeTask стабилен из-за useCallback. Также не происходит перерендер FilterButton, до оптимизации он перерисовывался каждый раз при изменении.

Анализ компонентов:
useTasks:
Фильтрация мемоизируется (filteredTasks) – пересчёт только при изменении tasks или filter.
Стабильная ссылка на функцию удаления (removeTask).

TaskCard:
Компонент обёрнут в React.memo, сравнивает task по ссылке и removeTask.

FilterButton:
Компонент обёрнут в React.memo.
